# 🌸 Buscas e Pragas - Enciclopédia Digital de Manejo Agrícola

Projeto desenvolvido para o concurso Agrinho

O **Buscas e Pragas** é uma plataforma digital e interativa projetada para auxiliar estudantes, agrônomos e produtores na identificação e no manejo sustentável do campo. O site funciona como um guia de consulta rápida, cobrindo as principais pragas e doenças que afetam o cultivo de **Soja, Milho e Hortaliças**.

### 🚀 Principais Recursos:

* **Banco de Dados Completo:** Cadastro detalhado de 48 pragas e doenças, incluindo o nome científico, descrição aprofundada dos sintomas e recomendações de controle biológico.
* **Busca e Filtragem Inteligente:** Sistema de pesquisa dinâmica que permite filtrar os problemas por cultura ou buscar diretamente por palavras-chave de sintomas (como *"mancha"*, *"furo"*, *"lagarta"*).
* **Interface Responsiva e Acessível:** Layout moderno e scannável desenvolvido com Tailwind CSS, incluindo um painel de instruções fixo no topo e suporte a **Modo Noturno** para leitura confortável em qualquer ambiente.

### 🛠️ Tecnologias Utilizadas:

* HTML5
* CSS3 (Customizado para Modo Noturno)
* Tailwind CSS (Estilização e Responsividade)
* JavaScript (Manipulação dinâmica de dados e filtros)
